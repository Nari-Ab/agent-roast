# Agent Roast 0.8 — аудит доверия к проверке и точечные исключения

Рабочая версия подготовлена после опубликованной 0.7.0. Новая цель: проверка должна
анализировать фактический коммит и объяснять каждое принятое исключение. Не обещать
обнаружение всех ошибок или доказанную полезность всем командам.

## Объём

- Действительные временные индексы Git hooks для commit -a/--only.
- Изоляция явного репозитория, ограниченные чтения и отсутствие записи через ссылки.
- Точность и производительность лексера/паттернов; отказ от ошибочной атрибуции людей.
- Точные исключения с count/reason/expires из доверенной policy, видимые в отчётах.
- Безопасные отчёты, честная неполная проверка и актуальные инструкции внедрения.
- Идеи из существующих открытых инструментов с первичными ссылками; новый код оригинален.

## Приёмка

Реальный commit -a с .only блокируется; чистый частичный коммит не блокируется чужими
staged файлами. Внешний GIT_DIR не меняет сканируемый проект. FIFO/ссылка policy и
патологический ignore glob не подвешивают программу. Не возникает ложных находок
на recatch, обычные имена людей, строки-примеры и Python import alias. Разделённые
по строкам/модификаторам пропуски тестов обнаруживаются. Принятое исключение не
скрывает дополнительный дубликат, не складывается с baseline и не принимается из
candidate-policy. Истечение срока возвращает находку; идентичность SARIF стабильна.

TypeScript и весь набор тестов на Node18/20/22 проходят, npm-архив устанавливается и
поддерживает эти сценарии. Публикация — отдельный шаг после этой реализации.
Пилоты из v060-plan.md по-прежнему необходимы: количество тестов не равно спросу,
удержанию, платёжной готовности или точности на реальных пользовательских проектах.

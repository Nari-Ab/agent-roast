# Agent Roast 0.8.0 — глубокий аудит и проверка

Дата: 28 октября 2026. База: опубликованная 0.7.0,
179e980042346a0352cf7bb469fd67046b527182. Статус: подготовлено локально, не опубликовано.

Это конечный инженерный аудит, а не доказательство отсутствия всех дефектов.
Проверены все runtime-модули, тесты и основные поверхности установки/представления.
Сохранены исходные пользовательские медиа и посторонние файлы. Внешние проекты
изучались по первичным источникам; чужая реализация не копировалась.

## Главное изменение для пользователя

Можно принять конкретную намеренную находку с причиной, сроком и **общим** числом
допустимых повторений, сохранив остальные проверки. Новые дубликаты не скрываются.
Baseline и исключение не складывают разрешения. В review политика берётся из
доверенного base/HEAD; candidate-config не может сам одобрить изменение. Принятые
находки видны отдельно и остаются в SARIF как accepted external suppressions.
При истечении срока полный check снова показывает находку. Review по-прежнему
блокирует новые находки, а не превращает неизменённый старый долг в новый.

## Проверка

- До изменений: 275 тестов 0.7.0 прошли.
- Итог: 447 тестов в27 файлах прошли на Node20.19.5 и22.20.0.
- Отдельный полный прогон: runner22 + CLI/API-subprocesses и реальные hooks на
  Node18.20.8, тоже447passed. Сам test runner4 требует Node20+, это не утверждение,
  что Vitest4 работает на Node18. CI воспроизводит CLI matrix18/20/22 на runner22.
- TypeScript typecheck, git diff --check и JS syntax checks прошли.
- Installed npm archive: CLI и exported API проверены на Node18/20/22; fingerprint,
  accepted exception, SARIF suppression, duplicate-after-baseline gate работают.
- schema.json и installed SARIF2.1.0 проверены Ajv8 + ajv-formats3, включая4
  негативных config controls. Живой GitHub code-scanning upload не выполнялся.
- 14 специально подобранных воспроизведений **уже известных** дефектов:0.7.0 не давала
  ожидаемый исход в14 случаях;0.8.0 даёт14/14. Это не репрезентативная выборка и не
  оценка production accuracy. Скрипт scripts/evaluate-080.mjs и JSON сохранены.
- Статический bundle test подтверждает отсутствие сетевых модулей/вызовов. npm
  установка и optional report uploads — отдельные сетевые операции.

См. отдельные logs: v080-node20-tests.txt, v080-node22-tests.txt, v080-cli18-tests.txt;
полные имена включают префикс2026-10-28. Сравнение и package smoke/schema/audit JSON

## Что ещё не обещаем

Лексер не является AST/import resolver; custom aliases, computed properties,
шаблонные интерполяции и смешанные Vue/Svelte/HTML regions не покрыты полностью.
Не все намеренные skips/stubs — дефекты. Новые исключения позволяют документировать
такие случаи; компилятор/тестовый runner/языковой linter всё равно необходимы.
Git reads имеют30s лимит **каждая команда**, не весь scan; проверка больших PR
по-прежнему делает отдельные reads для blobs. Реальные p50/p95 требуют пилота.
Файловые проверки не являются OS sandbox или защитой от всех привилегированных
конкурентных изменений родителей каталогов. Whole-project check не является единым
атомарным снимком изменяющейся рабочей копии; staged review фиксирует blobs и
перепроверяет inventory. Бинарные GIF/audio/video не пересоздавались и не доказывают
точность; сайт использует web font. Исторические планы сохранены как история решений.
Ни пользователей, ни инвесторов не контактировали; traction/ROI не выдумывались.

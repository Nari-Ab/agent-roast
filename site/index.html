What can go unnoticed

The Silent Regression

A change can skip a test, narrow the test run, or remove error handling while the remaining tests pass.

  • Skipped suites: it.skip() added to 3 test files. Critical edge cases never run.
  • Type evasion: Strict types suppressed with as any and // @ts-ignore.
  • Focused tests: test.only() can leave other tests unexecuted.
  • Review gap: A green status alone does not establish which behavior was checked.
What this review aid adds

New findings with source evidence

Run agent-roast --staged before committing or review --base origin/main before merging.

  • Exact citations: Reports repository-relative file, line and a concrete next step.
  • Clean type hygiene: Reports common suppressions and suspicious casts for review; legitimate exceptions exist.
  • Context comparison: Notices deletion-only empty handlers and separates existing findings from new ones.
  • Adoption: Use advisory mode first, agree on blocking rules, and keep compiling and testing the code.

Review new shortcuts in pull requests

Compare full changed source with policy from the trusted base commit. GitHub summaries and SARIF keep findings available for review.

.github/workflows/agent-roast.yml 
name: Agent Roast
on: [pull_request]

permissions:
  contents: read

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: Nari-Ab/agent-roast@v1
        with:
          mode: review
          base: ${{ github.event.pull_request.base.sha }}
          head: ${{ github.event.pull_request.head.sha }}
          format: github

Only new findings block

Compares full source at the merge-base and candidate head. Existing findings are counted separately; matching is heuristic, not semantic identity.

Choose what blocks

Defaults block skipped tests, focused tests and trivial assertions. Configure failOn or rule severities; other patterns are advisory by default. Panic loops are a history metric.

Isolated package installation

Installs a pinned CLI package in $RUNNER_TEMP with npm scripts disabled. Use read-only permissions and pull_request; pull_request_target is unsupported.

Inline Diff Annotations

Emits escaped GitHub annotations and a summary. Findings on unchanged lines may be visible only in the report/summary. Optional SARIF export is available; uploading is a separate step.

How it works

Focused heuristic checks without executing project code. Use them alongside language-aware linters, compilers and tests.

1. Check current code

agent-roast check scans tracked and non-ignored untracked source. No commit history or AI attribution is required; a Git repository is needed.

2. Compare full context

review --base origin/main compares complete changed files. Deleting the only catch handler is detectable even when no suspicious line was added.

3. Review source evidence

Masks common comments and literals to reduce noise. Each finding includes a next step. Complex syntax, aliases and template interpolation can still cause missed findings or false positives.

4. Verify the next commit

agent-roast --staged reads HEAD and the index. Unstaged repairs cannot hide a staged issue. Conflicts or a concurrent index/HEAD change require a rerun.

5. Adopt without hiding new debt

An explicitly reviewed baseline can accept current findings for check. Occurrence counts ensure another identical shortcut is still new. Baselines do not fix the code.

GitHub Action

6. PR Quality Gate (@v1)

Use the workflow above, or run npx agent-roast init --ci. Start advisory if needed with CLI --fail-on ''. Configure checks from evidence gathered in your own repository.

Offline analysis

The installed CLI does not upload source or call an LLM. Installing through npm/npx and uploading reports are separate network operations. This website loads a web font; reports you share may include source snippets.

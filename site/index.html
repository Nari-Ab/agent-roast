Hermetic Engine

How agent-roast audits without cloud or keys

⚡

Streaming Git Pipeline

Pipes git log -p -U0 with ASCII control record delimiters (\x1e / \x1f). Never loads the full repo into RAM.

🎯

Added-Lines Filter

Scans only added lines (+). Refactorings, file moves, and deleted code never produce false positives.

🛡️

Literal Sanitization

Strips string literals and fixtures before analysis, ensuring test strings like "it.skip" aren't flagged as infractions.

🤖

AI Fingerprinting

Extracts signatures from git trailers (Co-Authored-By: Claude), commit author tags, and tool provenance headers.

🔒

Zero Network & Telemetry

100% offline. No analytics, no phone-home ping, no external LLM dependencies. Your code never leaves localhost.

📦

CI/CD & JSON Ready

Run --json for pipeline reporting, or drop it into GitHub Actions to fail pull requests with sloppy shortcuts.

🔒 100% Hermetic Guarantee

Private code stays private. Period.

Unlike tools that upload your code to cloud models for "AI analysis", agent-roast is a deterministic static analyzer. It requires zero API keys, executes completely on your machine, and has zero network capabilities.
